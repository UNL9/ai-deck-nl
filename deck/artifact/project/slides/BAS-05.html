Een model ontstaat in drie stappen: pre-training, post-training en reinforcement learning

Per stap: welke data, wat het kost en wat het oplevert

Stap 1

Pre-training

Data

Enorme hoeveelheden tekst en code

Kosten

Maanden rekenwerk op duizenden chips

Resultaat

Een model dat tekst kan voortzetten

Stap 2

Post-training

Data

Voorbeelden van goede antwoorden en voorkeuren van mensen

Kosten

Weinig rekenkracht, veel menselijk werk

Resultaat

Een assistent die instructies volgt

Stap 3

Reinforcement learning

Data

Taken met een controleerbare uitkomst, zoals werkende code

Kosten

Groeiend: het model genereert zelf veel antwoorden

Resultaat

Een model dat redeneert en taken afmaakt

Het recept is inmiddels grotendeels openbaar.
